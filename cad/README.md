# Parts library

These are the parametric CAD parts for Ed's hardware. Each part has its own folder with the build123d script, a STEP file, a DXF and a drawing PNG.
Dimensions marked [A] are assumed and need checking with calipers. Status is either "listing" (dimensions from listings) or "measured".
