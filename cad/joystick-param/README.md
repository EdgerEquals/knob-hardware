# joystick-param — top-screen joystick sub-assembly (v0.1)

Parametric build123d model of the top-screen 5-way joystick: an Alps SKRHADE010 on a daughterboard
on a riser, a printed base with 4 pins and 4 ball seats, a carrier that slides on 4 Ø2 balls and is held down
by 4 extension springs, a spider spring with a plunger, and a cup over the stem. Design notes: `docs/top-screen-joystick.md`.

```
/workspace/cadenv/bin/python build.py              # build + checks (20 checks + pairwise clashes)
/workspace/cadenv/bin/python build.py --render     # + ../assemblies/joystick-v0.1/joystick-v0.1.png (A-A + iso + plan) and -plan.png
/workspace/cadenv/bin/python build.py --set spider_t=0.5 --set ball_d=2.5   # override params
/workspace/cadenv/bin/python build.py --step       # + STEP of the sub-assembly
```

- `jsparam/params.py`: `P` (tags: [A] assumed, [Ed] from Ed, [S] datasheet) and `derive()`.
- `jsparam/parts.py`: parts, all in the local frame. z is measured from the main-PCB front face. The origin is the carrier centre,
  which is knob frame (0, 31.8) and board (25.25, 21.1).
- `jsparam/checks.py`: the stem/cup gap, spider travel and margin, slide stop vs the 0.25 tilt, FPC/spring/board clearances, and
  the carrier vs the knob OD (read from knob-param, data only).
- `jsparam/render.py`: the colour PNG.

The KiCad daughterboard is at `cad/knob-param/knobparam/electronics/kicad/joystick-daughterboard/`. It is generated by
`make_project.py` (run with the system `python3`, which has pcbnew); the footprints come from `../make_joystick_footprints.py`.
Keep `sw_x`, `hdr_x`, the board size and the riser height in step with `make_project.py`
(`SW_X`, `HDR_X`, `BW`, `BH`).
