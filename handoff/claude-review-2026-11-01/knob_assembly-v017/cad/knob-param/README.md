# knob-param

Parametric CAD (build123d) for the motorised Eurorack knob, split into five sub-assemblies plus an
assembly layer that owns the interface params, cross-checks and render. Default = v0.16.

```bash
bash setup.sh && .venv/bin/python build.py --render     # -> ../assemblies/knob-stack-v0.16/
```

Workflow, contract and commands: [AGENTS.md](AGENTS.md).
