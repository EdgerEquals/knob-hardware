## How to work here
- Build: `cd cad/knob-param && KNOB_POOL=2 .venv/bin/python build.py` (minutes; run in the background). `--render` has a
  pre-existing blank inset: use `python -m knobparam.assembly.section_atlas`, `plan_sheet.cut/draw`, or pyvista under `xvfb-run -a`.
- The joystick stack is NOT in `build_all`: add it with `knobparam.assembly.joystick.placed()` (see the 3D quarter-cut recipe below).
- The cloud box has **2 cores / 7 GB**. Parallel jobs: one git worktree each (`git worktree add ../kh-<job> -b asm/<job> asm/layout-v4`),
  own `KNOBPARAM_CACHE=<worktree>/.cache-knob` (ignored), `KNOB_POOL=1`, `nice`. **Background jobs stop if the conversation is
  interrupted**: on 3 Nov three jobs died that way. While jobs run, send messages normally (no stop button).
- 3D quarter cut-away / straight-on cuts (what Danny asked for): build parts, add `joystick.placed()`, for each part
  `(shape & region_box) - quadrant_box`, tessellate, pyvista with `colour()` from `assembly/plan_sheet.py`, clear resin at
  opacity ~0.4, `add_point_labels`; parallel projection for straight-on cuts. Examples: `docs/img/js-quarter-v023.png`,
  `docs/img/js-sections-v023.png`.
