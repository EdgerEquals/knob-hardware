## How to build
- Model: `cad/knob-param/knobparam` (build123d, subs: electronics, control_dial, main_knob, base_drive, under_pcb, optics, case).
  Joystick: `cad/joystick-param` (read as data by the knob build: `knobparam/assembly/joystick.py`).
- Python venv with build123d, pyvista, shapely, matplotlib. On an 8 GB box use `KNOB_POOL=2` (the full build OOMs otherwise). A full build takes 4–5 min; run it in the background.
- From `cad/knob-param`:
  - `KNOB_POOL=2 python build.py` → checks + clashes (knob and joystick-vs-knob) → `cad/assemblies/knob-stack-v0.19/check.json`
  - `PYTHONPATH=. python -m knobparam.assembly.plan_sheet` → section sheet (13 plan cuts + 3 vertical cuts, now with the joystick)
  - `KNOB_POOL=2 python build.py --clean --no-check` → assembly render
  - `PYTHONPATH=. python -m knobparam.assembly.export_parts` → STEP per part + `parts.csv` (materials from `RULES`)
  - Joystick alone: `cd cad/joystick-param && python build.py` (also writes the daughterboard `geom.json`, including the holes it needs in the main PCB)
- Frames: mechanism parts are built with the 1220 at +X and turned by `mech_rot = -90` into the panel frame (`assembly/build.py view()`). Checks and clashes run in the mechanism frame; renders, exports and the joystick clash run in the panel frame.
- Colours: `assembly/colours.py` gives every part its real colour from its material (one table for renders, sheet and exported models). Magenta = a part the material rules do not place.
- Helper scripts: `cad/knob-param/tools/` (`pcb_windows.py` regenerates the PCB window polygons, `drv_spot.py` finds a free spot for the 716 driver, `cover_cuts.py` plots plan cuts through the back cover).
